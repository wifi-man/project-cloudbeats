# Sons de batterie

Déposez ici vos fichiers pour le kit virtuel :
`kick.wav`, `snare.wav`, `hihat.wav`, `tom1.wav`, `tom2.wav`, `floorTom.wav`, `crash.wav`, `ride.wav`

Pour la version publiée, placez les mêmes fichiers dans `public/sounds/drums/` afin qu'ils soient servis par l'application. Les fichiers MP3 sont acceptés (le lecteur essaie `.wav` puis `.mp3`).
