# Sons de xylophone

Déposez ici vos fichiers `c4.wav`, `d4.wav`, `e4.wav`, `f4.wav`, `g4.wav`, `a4.wav`, `b4.wav` et `c5.wav`.
Pour la version publiée, placez les mêmes fichiers dans `public/sounds/xylophone/` afin qu'ils soient servis par l'application. Les fichiers MP3 sont acceptés en adaptant leur extension dans `src/lib/audioStudio.js`.
